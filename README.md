# teamaicoder.com

The homepage for [TeamAICoder](https://github.com/teamaicoder/teamai-desktop), served by GitHub Pages at https://teamaicoder.com.

A single static `index.html` with no build step. The download buttons look up the latest release's assets through the GitHub API in the browser, so they pick up a new release without redeploying the site.

Preview locally: `python3 -m http.server` and open http://localhost:8000.
